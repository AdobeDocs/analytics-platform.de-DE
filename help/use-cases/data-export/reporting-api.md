# Reporting-API

In diesem Artikel wird beschrieben, wie die [!DNL Customer Journey Analytics Reporting API] zur Implementierung des folgenden [Anwendungsfalls für den Datenexport“ verwendet &#x200B;](overview.md) kann:

- Benutzerdefinierte Anwendungsintegration

## Einführung

Mit dem [!DNL Customer Journey Analytics Reporting API] können Sie dieselben verarbeiteten Dimensionen und Metriken, die in Analysis Workspace verfügbar sind, programmgesteuert abrufen. Verwenden Sie die [!DNL Reporting API], um benutzerdefinierte Programme zu betreiben, Berichte in interne Tools einzubetten oder den Abruf von Customer Journey Analytics-Daten ohne manuellen Export zu automatisieren.

## Weitere Informationen

Der [!DNL Reporting API] verwendet dasselbe Anfrage- und Antwortformat wie der [!DNL Adobe Analytics]-[!DNL Reporting API], verwendet jedoch einen anderen Endpunkt. Wenn Sie Reporting-Integrationen aus [!DNL Adobe Analytics] migrieren, finden Sie im Migrations-Workflow in der [Schnellstartanleitung](/help/getting-started/cja-getting-started.md) weitere Informationen.

Informationen zur Authentifizierung, zu verfügbaren Endpunkten und zu aktuellen Anfragebeschränkungen finden Sie in der [Customer Journey Analytics-API-Dokumentation](https://developer.adobe.com/cja-apis/docs/).
