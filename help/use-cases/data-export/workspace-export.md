# Workspace-Export

In diesem Artikel wird beschrieben, wie Analysis Workspace-Exportoptionen verwendet werden können, um den folgenden [Anwendungsfall für den Datenexport“ zu ](overview.md):

- Ad-hoc- und wiederkehrende Berichte

## Einführung

Durch den direkten Export von Daten aus Analysis Workspace können einzelne Benutzer ein Projekt herunterladen oder per E-Mail versenden, ohne ein Cloud-Ziel oder eine Datenpipeline einrichten zu müssen.

## Weitere Informationen

Sie können ein Projekt oder einen Teil eines Projekts als PDF-, CSV- oder JSON-Datei von Analysis Workspace auf Ihre Workstation herunterladen. Downloads sind nur ad hoc und auf 50.000 Zeilen beschränkt. Weitere [ finden Sie unter „Auf ](/help/analysis-workspace/export/download-send.md) Workstation herunterladen.

Sie können ein Projekt auch per E-Mail an andere Benutzer in Ihrer Organisation senden, entweder ad hoc oder nach einem Zeitplan. E-Mail-Berichte sind auf 400 Zeilen beschränkt. Weitere [ finden Sie unter ](/help/analysis-workspace/export/t-schedule-report.md) an andere Benutzer senden .

Einen Vergleich aller Analysis Workspace-Exportmethoden, einschließlich des Exports vollständiger Tabellen in die Cloud, finden Sie unter [Exportübersicht](/help/analysis-workspace/export/export-project-overview.md).
